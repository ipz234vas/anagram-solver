# Installation & Setup

This guide will help you boot up the Anagram Solver locally.

## Prerequisites
Ensure you have **Node.js (v18+)** installed on your system.

## Running the Project

Choose your preferred package manager below. We have configured the project to work seamlessly across different environments.

import Tabs from '@theme/Tabs';

## Available Scripts

Our `package.json` includes several utility scripts for development and documentation:

| Command | Description |
|---|---|
| `npm run dev` | Starts the main game client on `localhost:5173`. |
| `npm run build` | Compiles the game into the `dist` folder for production. |
| `npm run lint` | Runs ESLint rules across the `src` directory. |
| `npm run docs` | Boots up this Docusaurus documentation server. |
