# Live UI Components

One of Docusaurus' greatest advantages is its native **MDX (Markdown + JSX)** integration. We don't just write static text about our code — we import and render our **actual, production-ready React components** directly inside this documentation page!

Because we integrated our Feature-Sliced Design paths into the Docusaurus Webpack compiler bundler, these components use the exact same styles and business logic files as the running game.

import { Button } from '../../../src/shared/ui/button/Button.jsx';
import { Card } from '../../../src/shared/ui/card/Card.jsx';
import { Modal } from '../../../src/shared/ui/modal/Modal.jsx';

### Code Specifications
```jsx title="src/shared/ui/button/Button.jsx"
import cn from '../../lib/cn.js';
import styles from './Button.module.css';

export function Button({ variant = 'primary', className, children, ...props }) {
    return (
        <button className={cn(styles.btn, styles[variant], className)} {...props}>
            {children}
        </button>
    );
}
```

## 3. Live Modal Portal Framework

Our `<Modal>` component relies on **React Portals** (`createPortal`) to detach itself from local DOM layers and mount directly onto `document.body`. This prevents parents from truncating modal layers via `overflow: hidden` properties.

### Component Demonstration
Click the controller button below to toggle a real, fully-functional instance of your custom `<Modal>` component:

export const ModalTrigger = () => {
  const [open, setOpen] = useState(false);
  return (
    <div style={{ textAlign: 'center', padding: '20px' }}>
      <Button variant="primary" onClick={() => setOpen(true)}>Launch Real Modal Portal 🚀</Button>
      <Modal isOpen={open} onClose={() => setOpen(false)} title="Interactive Documentation Portal" showCloseButton={true} hasBackdropBlur={true}>
        <p>Amazing! This is the exact modal framework from your game running natively inside Docusaurus markdown pages!</p>
        <div style={{ display: 'flex', justifyContent: 'flex-end', marginTop: '20px' }}>
          <Button variant="secondary" onClick={() => setOpen(false)}>Close Portal</Button>
        </div>
      </Modal>
    </div>
  );
};

<div style={{ background: 'var(--ifm-background-surface-color)', borderRadius: 'var(--ifm-global-radius)', border: '1px solid var(--ifm-color-emphasis-300)' }}>
  <ModalTrigger />
</div>
