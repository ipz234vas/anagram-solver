Welcome to the official technical documentation for the **Anagram Solver** project.

## What is Anagram Solver?
Anagram Solver is a highly optimized, client-side web application that challenges players to unscramble letters into valid words within a strict time limit.

Unlike traditional monolithic React applications, this project is built from the ground up focusing on **modularity, strict data flow, and privacy compliance**.

## Technology Stack
Our application leverages modern frontend tooling to ensure maximum performance and developer experience:

* **Core Framework:** React 19
* **Build Tool:** Vite (for Lightning-fast HMR and optimized production builds)
* **State Management:** Zustand (for decoupled, atomic state slices)
* **Routing:** React Router v6
* **Architecture Pattern:** Feature-Sliced Design (FSD)
